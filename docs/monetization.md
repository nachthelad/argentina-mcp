# Monetization

## Future

Keep the public calendar tools available without an account. An optional account could link a user-owned API key and an OAuth connection to the same identity and quota. OAuth would support authenticated clients such as ChatGPT and Claude. API keys would cover programmable clients and clients that accept custom headers.

A paid RapidAPI subscription could activate a higher quota through a one-time linking code. Verify the RapidAPI proxy credential and the subscription before granting access. Confirm renewal and cancellation behavior on the public marketplace before committing to a linking flow. Measure upstream costs before choosing prices or quotas.

Keep receipt verification, billing state, usage accounting, and service credentials independent. Use a commercial hosting plan before enabling paid usage.
